# Laboration 4 - DT207G
Detta repository innehåller frontend för Laboration 4 i kursen DT207G. Webbplatsen är skapad med HTML, CSS och JavaScript och kommunicerar med en REST-webbtjänst via Fetch API.

Användare kan registrera konto, logga in och få åtkomst till en skyddad sida med hjälp av JWT.

## Av: Frida Ljungberg, 2026

### Funktionalitet
- Registrera användarkonto
- Logga in med användarkonto
- Validering av formulär innan anrop till API
- Tydliga felmeddelanden vid felaktig inmatning
- Lagring av JWT i Local Storage
- Skyddad undersida som kräver inloggning
